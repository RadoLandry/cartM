# Data Model: Discipline & Category Taxonomy`n`n## Entities`n`n### Product (Update)`n*Extends existing Prisma `Product` model.*`n- `disciplineTags` (JSON Array of strings): e.g., `["Boxing", "MMA"]``n- `categoryTags` (JSON Array of strings): e.g., `["Protection", "Equipment"]``n- `classificationConfidence` (Float, nullable): Overall confidence score from the LLM, or `1.0` if manually verified.`n- `isManuallyClassified` (Boolean, default: `false`): Flag to prevent automated syncs/classifiers from overwriting merchant decisions.`n`n## Relationships`n- **Product**: 1-to-many disciplines, 1-to-many categories.`n`n## Validation Rules`n- Discard or normalize any disciplines NOT in the predefined canonical taxonomy (e.g. `["Boxing", "Muay Thai", "BJJ", "MMA", "Fitness"]`).`n- Cannot have an empty discipline/category array after classification; must fallback to an "Uncategorized" bucket if the LLM fails completely.`n- Manual overrides immediately set `isManuallyClassified = true` and lock the entity.
